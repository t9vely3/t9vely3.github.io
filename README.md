# AIX 3부서 인트라넷 — 파일 구조와 수정 방법

```
index.html              인트라넷 껍데기 (왼쪽 메뉴, 통합 로그인, 화면 테마)
apps/manage.html        수강생 관리파일
apps/schedule.html      수강생 대시보드 (학사일정)
apps/quote.html         견적서
apps/viral.html         바이럴 관리
apps/notice-check.html  공지사이트 체크 관리
apps/guide-admin.html   수강생 안내 관리
apps/kuk-admin.html     국취 사전접수 관리
```

## 구동 원리

`index.html`은 메뉴와 로그인만 담당하고, 업무 화면은 `apps/` 폴더의 파일을 `<iframe src="apps/…">`로
그대로 불러옵니다. 그래서 업무 화면 하나를 고치려면 **그 파일 하나만** 바꿔 올리면 되고,
`index.html`은 건드리지 않아도 됩니다.

세 가지가 자동으로 적용됩니다.

1. **통합 로그인**: `index.html`이 프로젝트별 숨은 로그인 창을 띄워 같은 계정으로 로그인해 둡니다.
   같은 주소(도메인)에서 열리기 때문에 업무 화면은 이미 로그인된 상태로 시작합니다.
2. **화면 테마**: 업무 화면이 열릴 때 그 화면의 CSS 색만 네이비/모노 톤으로 바꿔 입힙니다.
   업무 화면 파일의 색을 직접 고치지 않아도 됩니다. 인쇄나 이미지 저장 때는 원래 색으로 돌아갑니다.
3. **메뉴**: 메뉴 이름·분류·순서는 인트라넷의 **메뉴 편집**에서 바꿉니다.
   바꾼 뒤 **파일에 고정 (내려받기)** 을 누르면 그 설정이 들어간 `index.html`을 받습니다. 그 파일로 바꿔 올리면 팀원 모두에게 같은 메뉴가 보입니다.

## 업무 화면 디자인을 고칠 때

- **색만 바꾸고 싶다** → 업무 화면 파일을 고치는 게 아니라 `index.html`의 테마를 고치는 쪽이 맞습니다.
  전체가 함께 바뀝니다.
- **레이아웃·기능을 바꾸고 싶다** → `apps/` 안의 그 파일을 고쳐서 같은 이름으로 덮어 올립니다.
  파일 이름을 바꾸면 `index.html`의 `app-files` 표에 있는 경로도 같이 바꿔야 합니다.

## 새 업무 화면을 추가할 때

1. HTML 파일을 `apps/` 폴더에 올립니다. (예: `apps/report.html`)
2. `index.html`에서 `id="app-files"` 부분에 한 줄 추가합니다.
   ```json
   "report": "apps/report.html"
   ```
3. 같은 파일의 `id="menu-config"` 부분에서 `apps` 목록에 한 줄 추가합니다.
   ```json
   {"src":"report","group":"student","name":"보고서","desc":"한 줄 설명","login":"통합 계정","icon":"doc"}
   ```
   `group`은 위쪽 `groups`에 있는 분류 id 중 하나입니다.
   `icon`은 users / chart / doc / check / lock / book / bell / home 중 하나입니다.
4. 그 화면이 쓰는 파이어베이스 프로젝트를 통합 로그인에 묶으려면 `id="sso-config"`의 `projects`에
   그 프로젝트의 웹 설정을 한 칸 추가합니다.

## 올릴 때 주의

- `index.html`과 `apps/` 폴더는 같은 위치에 있어야 합니다. (`apps/`를 다른 곳으로 옮기면 화면이 안 열립니다)
- 저장소 루트에 이미 다른 `index.html`이 있으면, 인트라넷은 `intra/` 같은 하위 폴더에
  `index.html` + `apps/`를 함께 넣으세요.
- 파이어베이스 각 프로젝트의 **승인된 도메인**에 이 사이트 주소가 들어 있어야 로그인이 됩니다.
- 바꿔 올린 뒤 화면이 그대로면 브라우저가 옛 파일을 들고 있는 것입니다. **Ctrl+Shift+R** 로 새로고침하세요.
